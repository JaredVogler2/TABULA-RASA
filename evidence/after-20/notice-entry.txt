# A notice was drawn half its width to the right while it faded in, then jumped to the centre

Found on 2026-11-26 while reading the measurements in notice-over-time-bar.txt: one reading had caught a
notice mid-entry, so its entry was looked at frame by frame.

A notice is centred with a transform of its own (`left: 50%; transform: translateX(-50%)`). Its entry used the
shared animation `rise`, which animates `transform` from `translateY(8px)` to `none` — and an animated
transform replaces the element's own. So for the quarter second of the entry the centring was gone: the notice
was drawn with its left edge at the centre of the screen, fading in, and when the animation ended it jumped
half its width to the left. A still picture shows a notice at rest, which is why none ever showed this.

Sampled on every frame from the moment the notice is added to the page (the probe is below; headless Chromium
with a software renderer, which draws few frames: what matters is the first one and the last).

## The probe (node toastanim.cjs <address> [width height])

// Scratch probe: where a notice is, frame by frame, from the moment it appears. node toastanim.cjs <base> [width height]
const { chromium } = require("playwright");
const base = process.argv[2];
const w = Number(process.argv[3] || 1366), h = Number(process.argv[4] || 768);
(async () => {
  const browser = await chromium.launch();
  const context = await browser.newContext({ viewport: { width: w, height: h } });
  const page = await context.newPage();
  await page.goto(`${base}/?q=low&pr=0.4`);
  await page.getByTestId("begin").click();
  await page.getByTestId("scenario-first_light").click();
  await page.getByTestId("seed-input").fill("7");
  await page.getByTestId("create-world").click();
  await page.getByTestId("world-label").waitFor({ state: "attached", timeout: 60000 });
  await page.getByTestId("coach-skip").click();
  await page.getByTestId("open-menu").click();
  // watch for the notice from before it is raised, and sample its box on every frame for 700 ms
  const samples = page.evaluate(
    () =>
      new Promise((resolve) => {
        const out = [];
        const obs = new MutationObserver(() => {
          const el = document.querySelector('[data-testid="toast"]');
          if (!el) return;
          obs.disconnect();
          const t0 = performance.now();
          const tick = () => {
            const r = el.getBoundingClientRect();
            const cs = getComputedStyle(el);
            out.push({ ms: Math.round(performance.now() - t0), left: Math.round(r.left), right: Math.round(r.right), top: Math.round(r.top), opacity: Number(cs.opacity).toFixed(2), transform: cs.transform });
            if (performance.now() - t0 < 700) requestAnimationFrame(tick);
            else resolve(out);
          };
          tick();
        });
        obs.observe(document.body, { childList: true, subtree: true });
      }),
  );
  await page.getByTestId("save-game").click();
  const got = await samples;
  const first = got[0], last = got[got.length - 1];
  console.log(`viewport ${w}x${h}; ${got.length} frames sampled`);
  for (const s of [got[0], got[1], got[Math.floor(got.length / 2)], last].filter(Boolean)) console.log(`  +${String(s.ms).padStart(3)} ms: left ${s.left}, right ${s.right}, top ${s.top}, opacity ${s.opacity}, transform ${s.transform}`);
  const centre = (s) => (s.left + s.right) / 2;
  console.log(`  centre of the notice: first frame ${centre(first)}, at rest ${centre(last)}, screen centre ${w / 2}`);
  await browser.close();
})().catch((e) => { console.error(String(e).slice(0, 800)); process.exit(1); });
