The charter is offered, lapses unsigned 288 ticks later, and is offered again 23 ticks after that, eight times,
until it is signed on day 33. For those 23 ticks nothing is on offer or in force, and the panel shows the
lapsed charter where it shows lapsed charters: folded away under "Lapsed and ended".

order of the engine's books, and lapsed ones are dropped from the books five days after they lapse:

`charter-157` is first, with nothing live above it, only from tick 1826 to tick 1849. The failed run stopped
its world there: on day 19, more than 1,200 ticks — nine and a half seconds at that speed — after the charter
was first offered. The panel did what it does; the test failed for where the world stopped.

## What was changed

The test no longer runs the world at speed. It steps it, a quarter of a day at a time, until the top bar counts
a charter: steps land exactly on any machine, and in this world that is tick 624, with the charter offered at
tick 601 on offer. It asserts that state (`data-state="proposed"`) before reading the charter's words.

## The probes

### scripted.ts — what becomes of the charter

// Scratch: when is the scripted charter of First Light seed 1 offered, and what becomes of it?
import { createWorld, makeConfig, step, type SimEvent } from "../../src/engine";
const w = createWorld(makeConfig("first_light", 1, { institutions: "scripted_control" }));
const out: SimEvent[] = [];
const kinds = new Set(["proposed", "proposal_rejected", "ratified", "lapsed", "ended", "dissolved", "joined", "left"]);
let joined = 0, left = 0;
for (let t = 0; t < 96 * 40; t++) {
  step(w, out);
  for (const e of out) {
    if (!kinds.has(e.k)) continue;
    if (e.k === "joined") { joined++; continue; }
    if (e.k === "left") { left++; continue; }
    console.log(`tick ${e.t} (day ${Math.floor(e.t / 96)}): ${e.k} ${JSON.stringify(e.d ?? {}).slice(0, 120)}`);
  }
  out.length = 0;
  if (t % 96 === 95) {
    const live = w.inst.institutions.filter((i) => i.ended < 0).length;
    const open = w.inst.proposals.filter((p) => p.state === "open").length;
    const lapsed = w.inst.proposals.filter((p) => p.state === "lapsed").length;
    if (live + open + lapsed > 0 && Math.floor(t / 96) % 2 === 0) console.log(`  end of day ${Math.floor(t / 96)}: ${live} in force, ${open} on offer, ${lapsed} lapsed; joined ${joined}, left ${left}`);
  }
}

### scripted2.ts — when nothing is live

// Scratch: for First Light seed 1 with the scripted control, the ticks at which no charter is live
// (nothing on offer and nothing in force) although one has been offered before.
import { createWorld, makeConfig, step, type SimEvent } from "../../src/engine";
const w = createWorld(makeConfig("first_light", 1, { institutions: "scripted_control" }));
const out: SimEvent[] = [];
let first = -1;
let gapStart = -1;
const gaps: [number, number][] = [];
for (let t = 0; t < 96 * 40; t++) {
  step(w, out);
  out.length = 0;
  const live = w.inst.institutions.filter((i) => i.ended < 0).length + w.inst.proposals.filter((p) => p.state === "open").length;
  const any = w.inst.institutions.length + w.inst.proposals.length;
  if (first < 0 && any > 0) first = w.tick;
  if (first >= 0) {
    if (live === 0 && gapStart < 0) gapStart = w.tick;
    if (live > 0 && gapStart >= 0) { gaps.push([gapStart, w.tick]); gapStart = -1; }
  }
}
console.log("first offered at tick", first, "day", Math.floor(first / 96));
for (const [a, b] of gaps) console.log(`nothing live from tick ${a} to ${b} (${b - a} ticks; day ${Math.floor(a / 96)}, tick of day ${a % 96})`);
const total = gaps.reduce((s, [a, b]) => s + (b - a), 0);
console.log(`in all ${total} ticks of ${96 * 40 - first} after the first offer: ${(100 * total / (96 * 40 - first)).toFixed(1)}%`);

### scripted4.ts — which charters the panel lists in each such stretch

// Scratch: in each stretch with nothing live, which charters are on the books, in the order the panel lists them?
import { createWorld, makeConfig, step, type SimEvent } from "../../src/engine";
const w = createWorld(makeConfig("first_light", 1, { institutions: "scripted_control" }));
const out: SimEvent[] = [];
let inGap = false;
let seen = false;
for (let t = 0; t < 96 * 34; t++) {
  step(w, out);
  out.length = 0;
  const live = w.inst.institutions.filter((i) => i.ended < 0).length + w.inst.proposals.filter((p) => p.state === "open").length;
  if (w.inst.proposals.length) seen = true;
  if (!seen) continue;
  if (live === 0 && !inGap) {
    inGap = true;
    console.log(`from tick ${w.tick}: on the books, in order: ${w.inst.proposals.map((p) => `${p.id} (${p.state})`).join(", ")}`);
  }
  if (live > 0) inGap = false;
}
