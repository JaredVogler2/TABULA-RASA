# 12-OBSERVER-UX — Observer controls and compelling game experience

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Design UI as an understated atlas/field journal with warm parchment + deep forest tones, luminous restrained accents, polished typography, clear icons and unobtrusive HUD. Main experience is the world: title intro with live 3D vista, timebar, contextual agent inspector, settlement map, event Chronicle, social network overlay, institution ledger, resource and population summaries. Timeline scrub and replay; jump to moments and actors. Filter by causal event, group or resource. Interaction: follow citizen, see what they know vs what observer knows, read concise decision rationale and witnessed events, compare intentions vs outcomes. Intervention palette: environment shocks, resource placement/withdrawal where authorized by scenario, migration/starting-condition changes, communication constraints. Explicitly distinguish observer and treatment modifications; no direct control of AI minds unless labeled separate mode. Preview consequences as uncertain; never invent forecast. Optional challenge objectives, meaningful dilemmas, unlock knowledge through observation not grind, natural short session arcs. Design responsive portrait and landscape layouts; bottom sheets on phone; 44px touch controls, keyboard, contrast, text labels, reduced motion, pause, audio sliders. Add procedural ambient sound/music original or licensed, meaningful event cues; no autoplay violations.
Gate: real desktop and mobile test flows covering play, follow, inspect, intervention, replay, compare and resume; accessibility checks plus visual inspection, no modal dead ends, usability review with explicit human-playtest gap.
