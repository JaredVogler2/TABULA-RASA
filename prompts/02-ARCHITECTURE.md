Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Choose and justify framework using current version-matched docs. Suggested Next.js + TypeScript + React Three Fiber/Three.js, Vercel Node runtime, pnpm, Vitest, Playwright, Zod, IndexedDB for free local games, durable transactional PostgreSQL for live runs. Separate pure simulation domain, view/render adapter, agent interfaces, server model gateway, persistence, experiment runner, UI, and test harness. Never import secrets into client bundles. Choose explicit fixed simulation tick, slower decision epochs, worker messaging, immutable versioned snapshots, typed event protocol, and deterministic PRNG with separate per-agent/per-process streams. Use server-authoritative live worlds and one durable job per decision epoch with lease, cancellation, bounded concurrency and optimistic version checks; keep local demo engine identical. No resident Vercel process, no in-memory authoritative budget, no full world in every request. Research Vercel duration limits and current workflow/queue options; choose durable bounded steps and resumable jobs, polling or supported streaming. Local dev requires no external services unless exercising live integration; provide test doubles and local DB migration instructions. Write ADRs including direct Anthropic API vs gateway BYOK billing (owner credits must actually be charged to Anthropic), public vs private modes, failure modes and threat model.
