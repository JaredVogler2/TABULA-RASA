# 14-EXPERIMENT-LAB — Scientific lab, benchmark scenarios and automated research

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Build research mode with experiment wizard, hypotheses, independent/dependent variables, seed sets, run manifests, budget preview, power/precision considerations, baseline controls, statistical analysis and exportable JSON/CSV. Initial studies: scarcity vs voluntary cooperation, mobility vs specialization, communication range vs institution adoption, diversity vs resilience, cognitive cadence vs performance and costs, LLM vs non-LLM vs scripted institution control. Use matched initial states, multiple independent seeds, holdout seeds, control for budget/cognition exposure, effect sizes and uncertainty, multiple comparisons warnings and missing-run reporting. Pre-register operational emergence definitions and criteria (observable adoption, use, persistence, material effect); record human/model-coded classification with uncertainty, separate inference from verified event. Develop automatic hypothesis agent optionally: may suggest experiments in structured form, cannot start paid runs or change protocol without owner approval, cannot alter evidence. Offline batch runner supports checkpoints/cancel; live study uses durable queue, caps and explicit consent. Research UI with linked graphs, institution timelines, agent trajectories and replay examples. No scientific novelty claims without literature review, independent replication and explicit caveats. 
Gate: execute at least 100 actual offline runs across registered conditions or report resource-limited count, reproducible statistics, fixtures verifying metric computations, downloadable study bundle, cost estimator tested. Live runs optional/authorized only.
