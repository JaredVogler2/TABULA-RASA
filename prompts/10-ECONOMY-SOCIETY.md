# 10-ECONOMY-SOCIETY — Endogenous economy, social graph and culture

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Develop meaningful material scarcity, asymmetric capabilities, production chains from generic recipes, search costs and time constraints. Allow agents to discover specialization, exchanges, common standards, tokens or accounting via existing generic transfer/commitment rules; avoid assigning jobs, salary, prices or money by default. Build social graph with communication, kinship only if modeled, trust, cooperation, agreements, conflict and membership as observed events. Culture is expressed through memories, repeated practices, stories and group norms, not seeded institutions. If introducing generations, births or inheritance, keep explicitly optional treatment and define assumptions, avoid forced or sensational content. Implement emergent patterns metrics: survival, resource inequality (Gini definition including zero cases), cooperation/reciprocity, specialization entropy, productivity, network modularity, trade volume, institution persistence, collective action success, concentration of decision influence. Separate descriptive metrics from normative scores. Measure events rather than rely on model self-reports. Establish resource accounting, time tradeoffs and credible failure pathways. 
Gate: test cases for exchange conservation, scarcity shock, trust/commitment updates, contract breach, group dissolution and metric correctness; baseline and live paths share mechanics. No claimed emergence based on example fixtures.
