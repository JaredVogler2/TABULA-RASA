# 05-AGENT-COGNITION — Agent cognitive architecture and baseline policies

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Create bounded individual cognitive state: identity, traits, learned skill, goals/preferences, episodic and semantic memory, social trust, commitments and locally perceived facts with provenance and confidence. Agent cannot see global state or private conversations unless informed. Distinguish perception, belief, plan, intent, action and outcome; never expose hidden world truth in agent context. Use spatial perception, bounded time/attention, decay, memory relevance scoring, summary provenance, contradiction handling and explicit unknowns. Design reproducible non-LLM policies: simple reflex, bounded rational planning and optionally evolutionary policy; none should be deliberately weak. Implement model adapter contract for one or more decisions with schema validation and action masks. Model suggestions do not write world state. Use agent-specific contextual prompts, constrained action catalogue, max actions/decision, bounded deliberation. Store concise declared rationale, not hidden chain-of-thought. Label source of each decision (baseline, mock, live, replay, fallback). Test memory leakage, belief staleness, trust updates and rational baseline behavior under common scenarios. 
Gate: distinct agents behave differently for documented reasons, private information remains private, replay uses recorded intents, headless tests compare baseline competence, no scripted institution emergence.
