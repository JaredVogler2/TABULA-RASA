# 08-AGENT-ORCHESTRATION — Multi-agent scheduling, communication and cognition efficiency

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Make LLM cognition sparse and economically meaningful: deterministic micro-actions each tick; strategic deliberation on bounded cadence, novel events, conflict, learning opportunities or proposed institutions. Compare round-robin, event-triggered and value-of-information scheduler on same seeds. Fairness: prevent the most talkative agents from monopolizing calls; use per-agent caps and explicit activation reasons. Run snapshot-based parallel independent decisions where valid; resolve using stable order and recorded outcomes, discard stale intents or revalidate against current state. Never assume provider output is deterministic; exact replay is based on stored responses. Explore small-batch multi-agent calls only as labeled experimental treatment because shared context can contaminate independent agents; prefer one agent per context for main treatment. Use private direct messages, public speech within distance, bounded group meeting affordances; model delivery delays and trust. No omniscient coordination. Cap message length/recipients, detect loops and starvation, compact memory with provenance. Plan approximate costs per decision epoch and per 50-agent study; preview using current prices, output cap, cache misses, no fictitious savings. Batch asynchronous research calls only if official API supports it and sequential dependencies preserved. 
Gate: 50 agents participate independently, scheduling trace, deterministic replay, cancellation/resume under injected errors, mock run across multiple epochs; compare cost and quality of activation policies without spending unless approved.
