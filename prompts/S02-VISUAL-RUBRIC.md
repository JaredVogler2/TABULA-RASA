# Specialist — art production and visual QA

Deliver an original naturalistic stylized miniature world, not flat cards over a generic grid. Art pillars: tactile landforms, readable human-scale silhouettes, lush flora, visibly traversed pathways, clear resource interactions, cinematic but legible lighting, slow ambient movement, warm/cool contrast and disciplined UI. Build title scene, close-up citizen, world-wide vista, night/rain, institution meeting, branch compare and phone portrait. Each shot must be captured from actual working product; label concept references separately. Require reference board with licensing/attribution, consistent color and material palette, geometry and animation standards, typography and icon system.
Score each 0–4: terrain/vegetation detail, citizen animation, lighting/materials, camera and composition, state readability, layout/typography, mobile interaction, visual originality, performance and accessibility. 0 absent; 1 placeholder; 2 functional; 3 polished; 4 exceptional verified. Aim >=3 each, no fabricated scores. Run at least three screenshot critique cycles: capture → inspect actual image → diagnose → modify → recapture. Verify actual action animation, depletion and building causally follow state. Include mobile 390x844 and landscape, desktop 1366x768 and 1920x1080 where possible. Test reduced motion/low quality; actual iPhone hardware if available, otherwise label emulation. Record FPS with device and preset. No expensive assets/services without approval.
