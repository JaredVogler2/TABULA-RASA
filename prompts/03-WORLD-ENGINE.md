# 03-WORLD-ENGINE — Deterministic world and ecology

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Implement the world as an independently testable simulation, not UI state. Generate seed-controlled land, streams, vegetation, elevations, weather/season cycles, renewable and finite resources, traversable tiles/navmesh, occupancy, material storage, agents' locations, survival needs and physical work. Build actions for moving, gathering, eating, resting, building from generic material recipes, giving/receiving, communication and inspecting; define explicit prerequisites, durations, capacity, costs and failure outcomes. Separate intent, validation, conflict arbitration and application. Use fixed-point/integer accounting where sensible; establish stable iteration order, independent PRNG streams, no wall-clock/randomness in reducer, canonical serialization and hash. Model resource transformations with declared sources/sinks and no negative inventories. Resolve simultaneous conflicts deterministically without systematically privileging one agent. Include hunger/exposure/fatigue and disease only where justified; death is a state transition, not gratuitous imagery. Design minimal default objectives as physiological needs plus diverse preferences, not a hidden civilizational script. Record detailed events with actor, time, reason code, delta and causal parents. Add save schema migrations.
Gate: 50 agents, one scenario with at least 1000 headless ticks, deterministic hash under replay, resource balances, invalid action rejection, property tests, reproducible seed and useful trace. Benchmark 100/500 agents separately; no performance promises without measurements.
