# 11-ART-DIRECTION — Visual identity and production-quality 3D environment

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Target an original premium miniature-world aesthetic: hand-crafted natural terrain, mossy stone, warm timber, sculpted cliffs, luminous shallow water, layered foliage, weather, soft shadows, ambient occlusion and cinematic lighting. Think museum diorama meets a living strategy game, not a dashboard with cubes. Create art bible with palette, silhouette language, camera/scale, materials, lighting, typography, icons, sound and mood references; no copying third-party IP. Build procedural or legally licensed assets with manifest, consistent scale, rich shapes, believable environmental detail, citizen silhouettes, animation cycles (walk, gather, carry, eat, rest, talk, build), paths, structures and resource depletion visible from real sim state. Gradually represent new institutions visually through physical artifacts only when actual events justify them; no automatic epoch unlocks. Use instancing, LOD, culling, shared materials, texture compression, adaptive resolution/shadows, WebGL2 fallback; WebGPU only if benchmarked, gracefully degrade. Camera orbit, pan, zoom, focus and unobstructed labels. Implement water, time-of-day, particles and weather within performance budget. Produce screenshot comparisons across iterations and review composition, readability, originality, visual clutter, mobile controls. Never use images as fake gameplay screenshots.
Gate: at least three screenshot-led visual critique/redesign passes; live play screenshots on desktop/mobile, annotated score rubric, evidence of animated actions and actual simulation linkage. Target 60 FPS desktop/30 FPS mobile with measured device and workload; disclose headless-only tests.
