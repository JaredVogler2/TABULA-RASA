# 07-BUDGET-SECURITY — Financial guardrails, secret handling and abuse prevention

Read CLAUDE.md and prompts/00-MASTER.md. Implement this phase; record evidence, update progress, commit.

Treat $200 as a maximum stated credit envelope, not permission to spend it. Default LIVE_ENABLED=false, zero budget until owner configures and explicitly authorizes; suggested smoke authorization $2, pilot $10, larger studies separately approved. Reserve at least $20 contingency in planning; refuse any run whose maximum estimated cost exceeds configured available balance. Use integer microdollars, durable transactional ledger shared by all instances and all users, per-run/daily/global hard ceilings, request-level maximum token reservations including uncached input, cache writes, output/reasoning, retries and documented price margins. Atomically reserve before dispatch; reconcile actual provider-reported usage; unknown outcomes retain conservative reservation; no duplicate dispatch on retry without explicit accounting. Fail closed on DB outage, stale pricing, missing usage, unknown model, invalid key or exceeded quotas. Avoid false hard-cap guarantee outside this app (other apps/provider billing); recommend provider workspace/project limits if supported. Show reserved/settled/remaining/unknown amounts, tokens, model, time and per-run cost; approval screen previews upper bound and allows cancel. Owner-authenticated live endpoints, CSRF/origin checks, schema/size validation, rate limit and request idempotency, admin kill switch; public users only offline or published recordings. Keys only server env/local ignored .env, no NEXT_PUBLIC, no logs/client config; rotate on leak. Preview deployments default mock, prod live explicitly enabled. Avoid user-supplied raw API proxy. Restrict arbitrary texts to in-world data; no arbitrary URLs, eval, shell or database commands. 
Gate: tests prove 100 concurrent requests cannot overspend app ledger, duplicate/reordered requests cannot double charge, unknown outcomes don't free funds, kill switch works, unauthenticated requests never call provider, client bundle/log/secret scans pass. Budget is measured not aspirational; zero live charges during development unless separately approved.
